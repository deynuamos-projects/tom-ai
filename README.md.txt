# Tom AI 🤖

A smart terminal chatbot built with Python while learning the language from scratch.

## About
Tom AI is my first portfolio project. He answers questions about me, 
shows my contact details, and pitches my skills as a developer from Accra, Ghana 🇬🇭

## What Tom Can Do
**1. About Me & Portfolio**
- `who built you` / `who created this` → My story + skills
- `show portfolio` / `projects` → Tom AI + future projects coming

**2. Contact & Hiring** 
- `hire him` / `can i hire` / `contact` → My email + WhatsApp
- `woah` → Fun reaction + contact drop

**3. Ghana Vibes 🇬🇭**
- `Roast Tom` → Tom drops friendly but unfriendly Ga, Twi, Ewe, Pidgin responds

**4. Features**
- **Smart keyword matching** - Understands sentences, not exact words
- **Colored terminal UI** - Contact info pops in blue, bot text in green  
- **Typing effect** - Text appears letter by letter like real AI
- **Self-pitch system** - Tom markets my skills automatically

## How to Run
1. Install Python 3
2. Clone this repo: `git clone <your-repo-link>`
3. Run in terminal: `python tom.py`
4. Start chatting with Tom!
